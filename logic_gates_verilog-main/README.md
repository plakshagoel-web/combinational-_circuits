# Logic Gates Implementation using Verilog 

## Overview

This project implements the basic digital logic gates using **Verilog
** in **Xilinx Vivado**. The design was verified through simulation
and analyzed using Vivado's design tools.

## Logic Gates

-   AND
-   OR
-   NOT
-   NAND
-   NOR
-   XOR
-   XNOR

## Tools Used

-   Verilog HDL
-   Xilinx Vivado

## Project Includes

-   Verilog source code
-   Testbench
-   Functional waveform
-   Elaborated Design
-   RTL Schematic
-   Synthesis Report
-   Power Report

## Learning Outcome

This project helped me understand basic combinational logic design,
Verilog syntax, simulation, and the synthesis flow in Vivado.
